Serveur : requêtes SQL paramétrées ; comparaisons de secrets en temps constant ; jetons signés HMAC-SHA-256 ; adresse du client crue seulement d'un pair de confiance ; aucun journal d'accès ; CSP stricte avec Trusted Types, HSTS ; aucun cookie ; origine exacte exigée sur le WebSocket ; réponses d'erreur fixes ; aucun secret par défaut ; webhooks Stripe et NOWPayments vérifiés avant toute lecture de base ; hôtes des prestataires fixes ; `go vet` et `go test -race` sans rien.

Déploiement et CI : images épinglées par empreinte, image finale `scratch`, utilisateur sans privilège, système de fichiers en lecture seule, réseau interne sans sortie, aucun journal dans Caddy, actions épinglées par SHA, aucun secret dans les workflows.

Site : aucun `{@html}`, `innerHTML` ni `eval` ; visionneuses limitées à une table fixe de types, PDF dans un cadre isolé ; fragment lu une fois puis retiré de l'adresse ; aucun `console.*` ; stockage local chiffré (AES-GCM, clé non extractible) ; aléa par `crypto.getRandomValues` partout ; contrôle d'intégrité SHA-384 sur chaque script et feuille de style ; aucune ressource tierce ; lecteur ZIP borné ; `npm audit` : 0 avis.
